## 🧠 Контекст для восстановления

### Архитектурные решения
- **Налог считается на уровне налогоплательщика (Organization), а не отдельного магазина.**
- **ПСН и УСН одного ИП — разные TaxRegistration.**
- **Ozon №1 и Ozon №2 ИП Леонтьева — разные SalesChannel одного УСН 6%, а не разные ИП.**
- **Банковская выписка не заменяет отчёт маркетплейса для налоговой выручки; она используется для сверки и других доходов.**
- **Альфа-эквайринг сверяется с ОФД/кассой; источник фискальной розничной выручки — касса/ОФД.**
- **API-ключи нельзя хранить в GitHub или передавать в экспорт для проверки.**
- **Сейчас данные ещё локально хранятся в `localStorage`; для коммерческой версии нужна серверная БД и разграничение доступа.**
